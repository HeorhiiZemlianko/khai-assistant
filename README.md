## ✨ Про проєкт

**Інтелектуальний помічник ХАІ** — це сучасний веб-додаток, який допомагає студентам, викладачам, абітурієнтам та адміністрації університету швидко знаходити відповіді на типові запитання.

Система побудована на **гібридній AI-архітектурі**, яка поєднує:

- ⚡ **Блискавичний локальний пошук** на основі алгоритму BM25
- 🧠 **Велику мовну модель** (LLM) через Groq API — для складних випадків
- 🎨 **Професійні шаблони відповідей** — для типових запитів
- 🛡️ **Quality Gate** — для валідації кожної відповіді перед показом

> 💡 **Головна перевага:** додаток повністю працює у браузері, не потребує бекенду та може бути розгорнутий як статичний сайт на GitHub Pages.

### Для кого цей проєкт?

| 👤 Роль | 🎯 Що отримує |
|---------|---------------|
| 🎓 **Студент** | Розклад, довідки, інформація про стипендію, гуртожиток |
| 👨‍🏫 **Викладач** | Розклад, наукові конференції, публікації |
| 🎒 **Абітурієнт** | Правила прийому, спеціальності, конкурсний бал |
| 🏛️ **Адміністрація** | Швидкий доступ до контактів та навчальних платформ |

## 🏗️ Архітектура

Додаток побудований як **п'ятишарова система**, де кожен шар відповідає за свою частину обробки запиту.

```
┌─────────────────────────────────────────────────────────┐
│  👤 Користувач  →  "Який розклад у групи 545б?"         │
└───────────────────────┬─────────────────────────────────┘
                        │
                        ▼
        ┌───────────────────────────────┐
        │  1️⃣  Класифікатор намірів      │  intent-classifier.ts
        │  (правила + ключові слова)    │
        └───────────────┬───────────────┘
                        │  intent: schedule_group
                        ▼
        ┌───────────────────────────────┐
        │  2️⃣  Пошуковий рушій BM25      │  retrieval.ts
        │  (топ-5 релевантних чанків)   │
        └───────────────┬───────────────┘
                        │  confidence: 0.87
                        ▼
        ┌───────────────────────────────┐
        │  3️⃣  Шаблонний генератор       │  response-templates.ts
        │  (10+ готових шаблонів)       │
        └───────────────┬───────────────┘
                        │  confidence < 0.4?
                        ▼
        ┌───────────────────────────────┐
        │  4️⃣  Groq LLM (опціонально)    │  llm-groq.ts
        │  (через Cloudflare Worker)    │
        └───────────────┬───────────────┘
                        │
                        ▼
        ┌───────────────────────────────┐
        │  5️⃣  Quality Gate              │  quality-gate.ts
        │  (валідація відповіді)        │
        └───────────────┬───────────────┘
                        │
                        ▼
              ✅ Готова відповідь
```

### 1️⃣ Класифікатор намірів

**Файл:** `src/ai/intent-classifier.ts`

Визначає намір користувача на основі правил та ключових слів. Підтримує **15 типів інтенцій**:

| Інтенція | Опис | Приклад запиту |
|----------|------|----------------|
| `schedule_group` | Розклад групи | «Розклад 545б на понеділок» |
| `schedule_teacher` | Розклад викладача | «Коли пари у Іванова?» |
| `schedule_room` | Розклад аудиторії | «Що у 227с?» |
| `admission_rules` | Правила прийому | «Як вступити на 134?» |
| `admission_specialties` | Спеціальності | «Які є спеціальності?» |
| `admission_score` | Конкурсний бал | «Який прохідний бал?» |
| `documents` | Довідки | «Як отримати довідку?» |
| `dormitory` | Гуртожиток | «Як поселитися в гуртожиток?» |
| `conferences` | Конференції | «Найближчі конференції» |
| `publications` | Публікації | «Де опублікувати статтю?» |
| `contacts` | Контакти | «Телефон деканату» |
| `platforms` | Навчальні платформи | «Як зайти в Moodle?» |
| `payment` | Оплата навчання | «Реквізити для оплати» |
| `scholarship` | Стипендія | «Коли виплата стипендії?» |
| `unknown` | Невідомий намір | — |

**Витяг сутностей:**
- 🆔 Номер групи — `545б`, `525ст`
- 👤 Прізвище викладача
- 🚪 Аудиторія — `227с`
- 📅 День тижня
- 🎓 Код спеціальності — `134`, `121`

Результати кешуються для підвищення швидкості повторних запитів.

### 2️⃣ Пошуковий рушій BM25

**Файл:** `src/ai/retrieval.ts`

Локальний пошук за базою знань з використанням алгоритму **BM25** (Best Matching 25).

**Особливості:**

- 🏷️ **Заголовки чанків** мають підвищений пріоритет — вага **2.5x**
- 👥 **Роль користувача** (Студент, Викладач, Абітурієнт, Адміністрація) динамічно коригує релевантність — коефіцієнт **1.3x**
- 📊 Повертає **топ-5** найбільш релевантних фрагментів
- 🔀 Підтримує гібридний пошук з ембеддингами — `searchHybrid()`

### 3️⃣ Шаблонний генератор

**Файл:** `src/ai/response-templates.ts`

Містить **понад 10 професійно підготовлених шаблонів** відповідей з:
- 💬 Людяним тоном спілкування
- 😊 Емодзі для наочності
- 📋 Структурованими списками
- 🔗 Прямими посиланнями на ресурси ХАІ

Шаблони використовуються як **основний механізм генерації** — LLM залучається лише за потреби.

### 4️⃣ Опціональний Groq API

**Файл:** `src/ai/llm-groq.ts`

Для складних випадків, коли впевненість класифікатора низька (< 0.4), система звертається до **Groq API**.

- 🧠 Модель: `llama-3.3-70b-versatile`
- 🔐 Запити надсилаються через **Cloudflare Worker проксі** (API-ключ не потрапляє у фронтенд)
- 🔄 Якщо проксі не налаштовано — автоматичне перемикання на шаблонний режим

### 5️⃣ Quality Gate

**Файл:** `src/ai/quality-gate.ts`

Валідація відповіді перед відображенням:

- ✅ Перевірка довжини: **30–2500 символів**
- 🚫 Блокування дегенерації та повторів фраз довжиною **> 22 символів**
- 🔤 Контроль допустимих діапазонів Unicode та відсотка кирилиці

## ⚙️ Налаштування

Основні параметри знаходяться у файлі `src/config.ts`:

```typescript
export const CONFIG = {
  // URL Cloudflare Worker проксі для Groq API
  // Залиште порожнім, щоб використовувати лише шаблонний генератор
  GROQ_PROXY_URL: import.meta.env.VITE_GROQ_PROXY_URL
    || 'https://khai-groq-proxy.kibranec2.workers.dev',

  // Модель Groq
  GROQ_MODEL: "openai/gpt-oss-120b",

  // Поріг впевненості класифікатора, нижче якого залучається Groq або fallback
  LOW_CONFIDENCE_THRESHOLD: 0.4,

  // Мінімальний бал релевантності BM25
  MIN_RELEVANCE_SCORE: 0.15,
};
```

### 🔧 Параметри конфігурації

| Параметр | Тип | За замовчуванням | Опис |
|----------|-----|------------------|------|
| `GROQ_PROXY_URL` | `string` | URL воркера | Проксі для Groq API |
| `GROQ_MODEL` | `string` | `openai/gpt-oss-120b` | Назва моделі |
| `LOW_CONFIDENCE_THRESHOLD` | `number` | `0.4` | Поріг для fallback |
| `MIN_RELEVANCE_SCORE` | `number` | `0.15` | Мінімум BM25 |

### 🔐 Налаштування Groq API (опціонально)

1. Зареєструйтесь на [**Groq Console**](https://console.groq.com)
2. Створіть API-ключ у розділі **API Keys**
3. Створіть безкоштовний воркер у [**Cloudflare Workers**](https://workers.cloudflare.com)
4. Додайте секретну змінну `GROQ_API_KEY` у налаштуваннях воркера
5. Вкажіть URL воркера у `src/config.ts` як `GROQ_PROXY_URL`

> 💡 Якщо `GROQ_PROXY_URL` порожній — додаток працює **повністю на вбудованих шаблонах** без зовнішніх запитів.

## ❓ FAQ

<details>
<summary><b>❓ Чи потрібен бекенд для роботи додатку?</b></summary>

**Ні.** Додаток повністю статичний та працює у браузері. Єдиний зовнішній сервіс — Cloudflare Worker проксі для Groq API, і той опціональний.
</details>

<details>
<summary><b>❓ Скільки коштує використання Groq API?</b></summary>

Groq надає безкоштовний тариф з обмеженнями за кількістю запитів на хвилину/день. Для більшості навчальних сценаріїв цього достатньо.
</details>

<details>
<summary><b>❓ Що робити, якщо Groq не налаштовано?</b></summary>

Додаток автоматично перемикається на **шаблонний режим** і продовжує працювати. Функціональність залишається повноцінною для типових запитів.
</details>

<details>
<summary><b>❓ Як оновити базу знань?</b></summary>

Запустіть `npm run scrape`. Скрипт збере актуальну інформацію з сайтів ХАІ та оновить локальну базу знань.
</details>

<details>
<summary><b>❓ Чи можна використовувати додаток для іншого університету?</b></summary>

Так. Достатньо замінити базу знань, шаблони відповідей та, за потреби, адаптувати класифікатор намірів під специфіку закладу.
</details>

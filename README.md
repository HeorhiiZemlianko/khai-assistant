## Опис

**Інтелектуальний помічник ХАІ** — це веб-додаток, який відповідає на запитання студентів, викладачів, абітурієнтів та адміністрації університету. Система використовує **гібридну AI-архітектуру**, що поєднує швидкий локальний пошук на основі BM25 з опціональним залученням великої мовної моделі (LLM) через Groq API для складних випадків.

Додаток повністю працює у браузері, не потребує серверної частини та може бути розгорнутий як статичний сайт.

## Архітектура

Система складається з п'яти шарів, які забезпечують точність, швидкість та надійність відповідей.

### 1. Класифікатор намірів (`src/ai/intent-classifier.ts`)

Визначає намір користувача на основі правил та ключових слів. Підтримує такі інтенції:

- `schedule_group` — розклад групи
- `schedule_teacher` — розклад викладача
- `schedule_room` — розклад аудиторії
- `admission_rules` — правила прийому
- `admission_specialties` — спеціальності
- `admission_score` — конкурсний бал
- `documents` — довідки та документи
- `dormitory` — гуртожиток
- `conferences` — наукові конференції
- `publications` — публікації
- `contacts` — контакти
- `platforms` — навчальні платформи
- `payment` — оплата навчання
- `scholarship` — стипендія
- `unknown` — невідомий намір

Витягує сутності: номер групи (`545б`, `525ст`), викладача, аудиторію (`227с`), день тижня, код спеціальності (`134`, `121`). Використовує кешування для підвищення швидкості.

### 2. Пошуковий рушій BM25 (`src/ai/retrieval.ts`)

Локальний пошук за базою знань з використанням алгоритму **BM25**:

- Заголовки чанків мають підвищений пріоритет (вага 2.5x).
- Ролі користувача (Студент, Викладач, Абітурієнт, Адміністрація) динамічно коригують релевантність (коефіцієнт 1.3x для відповідної ролі).
- Повертає топ-5 найбільш релевантних фрагментів.
- Підтримує гібридний пошук з використанням ембеддингів (`searchHybrid`).

### 3. Шаблонний генератор (`src/ai/response-templates.ts`)

Містить понад 10 професійно підготовлених шаблонів відповідей з людським тоном, емодзі, списками та прямими посиланнями на ресурси ХАІ. Шаблони використовуються як основний механізм генерації відповідей.

### 4. Опціональний Groq API (`src/ai/llm-groq.ts`)

Для складних випадків, коли впевненість класифікатора низька, система може звернутися до **Groq API** з моделлю `llama-3.3-70b-versatile`. Запити надсилаються через безпечний Cloudflare Worker проксі. Якщо проксі не налаштовано, система автоматично перемикається на шаблонний режим.

### 5. Quality Gate (`src/ai/quality-gate.ts`)

Валідація відповіді перед відображенням:

- Перевірка довжини (30–2500 символів).
- Блокування дегенерації та повторів фраз довжиною >22 символів.
- Контроль допустимих діапазонів Unicode та відсотка кирилиці.

## Швидкий старт

### Встановлення залежностей

```bash
npm install
```

### Запуск локального сервера розробки

```bash
npm run dev
```

Додаток буде доступний за адресою `http://localhost:5173/khai-assistant/` (базовий шлях налаштовано у `vite.config.js`).

### Збірка для продакшену

```bash
npm run build
```

Вміст директорії `dist` готовий для публікації на GitHub Pages.

### Оновлення бази знань

```bash
npm run scrape
```

Запускає скрипт `scripts/scraper.js` для збору актуальної інформації з сайтів ХАІ.

## Налаштування

Основні параметри знаходяться у файлі `src/config.ts`:

```typescript
export const CONFIG = {
  // URL Cloudflare Worker проксі для Groq API
  // Залиште порожнім, щоб використовувати лише шаблонний генератор
  GROQ_PROXY_URL: import.meta.env.VITE_GROQ_PROXY_URL || 'https://khai-groq-proxy.kibranec2.workers.dev',

  // Модель Groq
  GROQ_MODEL: "openai/gpt-oss-120b",

  // Поріг впевненості класифікатора, нижче якого залучається Groq або fallback
  LOW_CONFIDENCE_THRESHOLD: 0.4,

  // Мінімальний бал релевантності BM25
  MIN_RELEVANCE_SCORE: 0.15,
};
```

### Налаштування Groq API (опціонально)

1. Зареєструйтесь на [Groq Console](https://console.groq.com).
2. Створіть API-ключ у розділі **API Keys**.
3. Створіть безкоштовний воркер у [Cloudflare Workers](https://workers.cloudflare.com).
4. Додайте секретну змінну середовища `GROQ_API_KEY` у налаштуваннях воркера.
5. Вставте URL воркера у `src/config.ts` як `GROQ_PROXY_URL`.
6. Якщо `GROQ_PROXY_URL` порожній, додаток працює повністю на вбудованих шаблонах без зовнішніх запитів.

## Технології

- **React 18** — бібліотека для побудови інтерфейсу
- **Vite 4** — швидкий збирач та сервер розробки
- **TypeScript** — типізована мова програмування
- **Tailwind CSS 3** — утилітарний CSS-фреймворк
- **Lucide React** — набір іконок
- **@xenova/transformers** — бібліотека для роботи з ембеддингами в браузері
- **Cheerio** — парсинг HTML для скрепера
- **gh-pages** — деплой на GitHub Pages
